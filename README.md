## 🔥 Currently Building: EWW (Enterprise Wide Web)

<div align="center">

<a href="https://github.com/sandhiya-s86">
  <img src="https://img.shields.io/badge/⭐_Flagship_Project-EWW-00B4D8?style=for-the-badge" alt="EWW"/>
</a>

</div>

> A knowledge platform that captures what developers know from their coding sessions and makes it searchable.

**What it does:**
- Captures developer activity from **Claude Code** and **GitHub**, extracts knowledge articles via **LLM agents**
- Serves through **hybrid search** — text matching + vector similarity + PageRank-style authority scoring
- Background job pipelines with **BullMQ** for LLM-powered knowledge extraction and embedding generation
- **MCP tooling** that lets developers search and write back knowledge from within their coding environment

**Built with:** `TypeScript` `NestJS` `PostgreSQL` `pgvector` `BullMQ` `Redis` `Mastra` `MCP SDK` `Turborepo`
